## 🚀 开源项目

### [`xieqingyu-studio`](https://github.com/XieQingYu-ProgramStudio/xieqingyu-studio) — WordPress 主题

一款为创作者与工作室打造的 **Neo-Brutalism（新粗野主义）** WordPress 主题。

- 🎨 3px 粗边框 + 硬阴影 + 紫/红/黄三色系统
- 📱 响应式布局 · 粘性导航 · 自定义 Logo
- 🧩 Gutenberg 区块编辑器兼容
- 🌐 多语言就绪 · 零外部依赖 · 纯手写 CSS
- 📦 仅 ~1049 行 CSS，轻量高效

```css
/* Neo-Brutalism Design Tokens */
--primary: #6C63FF;
--accent-1: #FF6B6B;
--accent-2: #FFD93D;
--border-w: 3px;
--shadow-off: 4px;
```
